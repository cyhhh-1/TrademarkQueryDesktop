# 主界面实现对照记录

- 参考图：`trademark-query-primary-screen.png`
- 实现图：`implementation-primary-screen.png`
- 基准视口：1440 × 900

## 视觉一致性检查

1. 顶栏保持 58 px，高亮蓝色“商”字应用标记、22 px 应用名、分隔线和“完全本地运行”副标题均与参考方向一致。
2. 四步轨道保持独立 96 px 区域，使用等距圆形步骤、连续线条和蓝/灰单色状态，不引入额外导航。
3. 工作区左栏固定 332 px，三段操作顺序、分隔线、描边按钮和禁用主按钮与参考图一致。
4. 右侧使用状态标题、六项无卡片统计、四列固定表头和占满剩余高度的任务表格；已修复可选提醒条缺席时表格高度塌缩的问题。
5. 可恢复暂停使用页面内琥珀提醒条，不使用模态框；`AUTH_BLOCKED` 会同步禁用“继续”，重新检测为 READY 后才重新启用。
6. 颜色固定为真白背景、`#D9E1EA` 结构线、`#10213A` 主文字、`#0B73E0` 主蓝、`#12A45A` 成功、`#F4A000` 提醒和 `#D7463F` 失败。
7. 所有业务按钮均有真实 disabled 状态、键盘焦点环和统一的 20 px 线性 SVG 图标。

## 文案差异

参考图展示的是“已选文件、浏览器已就绪但登录失效暂停”的业务样例；实现截图展示首次启动空状态，因此主标题显示“选择查询表格”，文件区显示“尚未选择 XLSX 文件”，表格显示“选择 XLSX 后，这里会显示待查询商标”。选择文件和收到 Worker 状态后，界面会切换为参考图中的真实文件名、模板名称、状态标题、暂停提示和任务行文案。

实现额外提供“未连接”“待进入查询页”“需要验证”“访问受限”四类必要运行状态文案，它们分别对应 Worker 的浏览器状态，不属于营销或装饰内容。
