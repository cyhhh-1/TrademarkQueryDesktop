# 商标查询助手 UI 视觉规格

- 状态：已确认，按内联方式实施
- 概念图：`docs/design/trademark-query-primary-screen.png`
- 生成方式：内置 Image Gen，`ui-mockup`
- 基准视口：1440 × 900

## 1. 视觉方向

这是一个供普通办公室员工使用的单任务桌面工具。界面采用真白背景、冷灰结构线、深海军蓝文字和单一蓝色主操作色。页面强调步骤、当前状态和下一步操作，不使用营销页结构、渐变、图片背景、数据图表或装饰卡片网格。

## 2. 布局

- 顶栏高度约 58 px，左侧显示蓝色“商”图标、“商标查询助手”和“完全本地运行”。
- 步骤轨道位于顶栏下方，高度约 96 px，包含“选择表格”“登录网站”“自动查询”“保存结果”。
- 工作区使用两栏布局：左侧固定 332 px，右侧占剩余宽度。
- 左侧按“选择表格”“登录网站”“开始查询”顺序放置工作流操作，以水平分隔线分组。
- 右侧顶部是可恢复错误的内联提醒条，其下是当前状态、统计数据、任务表格和底部操作区。
- 任务表格是主要内容，占据右侧可用高度；不将每一行改成卡片。

最小窗口为 1100 × 720。宽度不足时保持左侧不小于 284 px，压缩右侧统计间距和表格列，不隐藏主要按钮。首版不提供手机布局。

## 6. 组件与状态

### AppHeader

- 使用代码原生蓝色方形标记和“商”字，不使用国家知识产权局官方标志。
- 右侧只保留原生窗口控制，不增加导航。

### StepRail

- 四个等距步骤，当前步骤为蓝色实心圆和蓝色文字。
- 已完成步骤为蓝色，未开始步骤为灰色。
- 步骤切换只做 160 ms 以内的颜色过渡；减少动画模式下取消过渡。

### WorkflowSidebar

- 文件选择后显示文件图标、文件名、行数和大小。
- 模板类型使用普通输入框式只读区域，不使用胶囊标签。
- “打开商标网站”为描边按钮，“开始查询”为蓝色主按钮。
- 文件未通过校验或浏览器未就绪时，主按钮必须使用真实 `disabled`。

### BrowserStatus

- READY 使用绿色圆形勾号和“可查询”。
- LOGIN_REQUIRED 使用琥珀色状态和“需要登录”。
- AUTH_BLOCKED/WAF_BLOCKED 使用红色状态和对应中文说明。
- 状态图标采用同一套 2 px 圆角线条 SVG，不混用填充和描边风格。

### InterruptionBanner

- 仅在任务可恢复暂停时显示。
- 琥珀浅底、1 px 边框、左侧警示图标、右侧“重新检测”按钮。
- 不使用阻塞式模态框，不自动抢焦点。

### TaskSummary

- 六个紧凑数字区，使用细分隔线而不是卡片。
- 成功数字为绿色、失败数字为红色，其余保持正文色。

### TaskTable

- 固定表头，列为“行号”“商标”“阶段”“结果”。
- 采用轻灰表头、细结构线和白色正文行。
- 阶段前可显示 8 px 状态点；不使用装饰图标列。

### TaskActions

- 右对齐“继续”“取消任务”“另存为”。
- 禁用态降低对比度并禁止点击；可用态保持清晰键盘焦点。
- 完成后“另存为”成为主操作，但不改变按钮顺序。

## 7. 图标清单

- 应用标记：蓝色 32 px 圆角方块，白色“商”。
- 文件：Excel 文档含义，绿色单色，不使用 Microsoft 商标图形的精确复制。
- 打开外部网站：方框外箭头，2 px 描边。
- 开始/继续：向右三角，保持 16 px 光学尺寸。
- 取消：正方形停止符号。
- 另存为：软盘含义的简洁描边图标。
- 成功：圆形勾号。
- 警告：圆形感叹号。

所有图标使用 `currentColor`，统一 20 × 20 viewBox、圆角端点和光学居中。

## 8. 核心交互

1. 选择 XLSX 后，文件区更新并展示模板检测结果。
2. 点击“打开商标网站”启动专用 Edge，状态区域持续更新。
3. 浏览器为 READY 后启用“开始查询”。
4. Worker 行事件实时更新统计和表格行。
5. 登录失效时显示内联提醒、暂停任务并启用“重新检测”。
6. 恢复 READY 后启用“继续”。
7. 完成后启用“另存为”，由原生文件对话框选择路径。

## 9. Image Gen 提示词摘要

生成内容为 1440 × 900 的可实现中文 Windows 桌面产品界面，包含四步轨道、左侧工作流、右侧状态统计和任务表格，并展示登录失效的内联提醒状态。约束为真白背景、蓝色主色、无官方标志、无摄影、无渐变、无营销文案、无装饰卡片网格、无水印。
