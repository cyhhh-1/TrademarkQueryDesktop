## 新电脑准备

目标系统是 Windows 10/11 x64。需要 Python 3.11（带 py 启动器）、Node.js 22.12+ 或兼容的更新 LTS/npm、Rust MSVC 工具链、Visual Studio C++ Build Tools（含 Windows SDK）、Microsoft Edge 和 WebView2 Runtime。第一次安装依赖及 Rust 构建需要联网。

解压后在项目根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\setup-home-dev.ps1
```

脚本检查工具、创建 worker/.venv、安装 Python 和 npm 依赖、构建并暂存 Worker 资源。不会自动安装系统工具。首次执行耗时取决于网络和机器。开发壳明确使用 worker/.venv/Scripts/python.exe，不能直接拿其他电脑的虚拟环境过来用。

然后先关闭已安装的商标查询助手，运行：

```powershell
worker\.venv\Scripts\python.exe -m pytest worker\tests -q
npm --prefix apps\desktop test -- --run
npm --prefix apps\desktop run build
cargo test --manifest-path apps\desktop\src-tauri\Cargo.toml
```

启动开发窗口：

```powershell
Set-Location apps\desktop
npm run tauri -- dev
```

发版构建：在根目录运行 scripts/build-desktop.ps1。release 内附带的 0.1.26 安装包是本机现有产物，没有在本次打包中重新构建。旧员工手册标注 0.1.20，仅供参考。

```powershell

```

可选恢复已有 Git 历史（只在刚解压、尚未继续编辑的新目录执行）：

```powershell

git reset --mixed FETCH_HEAD
```

mixed reset 保留工作区文件，使相对于历史 HEAD 的改动重新显示。不要使用 reset --hard 或 checkout 覆盖快照源码。无需恢复历史也可直接阅读、运行和编辑。
